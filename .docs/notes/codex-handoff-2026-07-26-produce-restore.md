# Задание Codex: восстановить контур «Произвести» (решение владельца §1.6)

Основание: `PRODPLAN/mrp-decisions-log.md` §1.6 (внесено владельцем 26.07). Волна канона
снесла контур выпуска БЕЗ решения владельца — это откатывается ДО коммита волны.

## Зафиксированный сценарий (неизменяемый)

Оператор нажимает «Произвести» → PRODPLAN по OData одним действием создаёт
`Document_СборкаЗапасов` и `Document_СдельныйНаряд` → 1С проводит → PRODPLAN
тут же считывает регистр проведения и записывает факт через Item Ledger
(read-back). Создание документа фактом НЕ является — фактом является только
считанный назад результат проведения. Это соответствует §1.5 и §11.
