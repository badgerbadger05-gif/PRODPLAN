1) MRP работает **в дневном режиме**. Исторические weekly/bucket_type очищены.
2) Любые изменения моделей БД → миграция Alembic (+ обновить `db_schema.md`).
3) Контракты API стараемся не ломать.
4) Документы 1С из MRP (`ЗаказНаПроизводство`, `ЗаказПоставщику`) — первичные; дочерние (перемещение, сборка, сдельный наряд) — «на основании».

- Был кейс «ложная блокировка по комплектующим из-за неполного кэша остатков» → следить за полнотой кэшей stock.
- Есть контур «принудительных заказов» (manual override) + экспорт.
- В синхронизации спецификаций важен reconcile (удаление устаревших строк) и дедупликация `default_specifications`.
- `create_all` на импорте `main.py` — несущий: миграции не строят схему с нуля (`tech-debt.md` B1).
- Известные мины — `tech-debt.md`; остатки/резервы — `item_ledger.md`.
