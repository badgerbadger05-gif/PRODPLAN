# PRODPLAN: Быстрый старт

**Версия:** 2.0  
**Дата:** 2025-09-24

## 🚀 Что такое PRODPLAN

PRODPLAN — это система для планирования производства, построенная на современной архитектуре.

- **Backend**: FastAPI (Python)
- **Frontend**: Quasar (Vue.js, TypeScript)
- **База данных**: PostgreSQL
- **Окружение**: Docker

Система автоматизирует управление спецификациями (BOM), планирование производства, расчет потребностей и синхронизацию данных с 1С.

## ⚡ Быстрый запуск (5 минут)

### Шаг 1: Предварительные требования
- Установленный [Docker](https://docs.docker.com/get-docker/)
- Установленный [Docker Compose](https://docs.docker.com/compose/install/) (обычно идет в комплекте с Docker Desktop)

### Шаг 2: Запуск проекта

Для запуска всего стека приложений (база данных, backend, frontend) используйте один из следующих скриптов в корне проекта:

#### Для Windows:
```cmd
start.bat
```

#### Для Unix-систем (Linux/macOS):
```bash
./start.sh
```

Эти скрипты используют `docker-compose` для автоматического запуска всех сервисов.

### Шаг 3: Доступ к приложению

После успешного запуска сервисы будут доступны по следующим адресам:

- **Frontend (веб-интерфейс)**: [http://localhost:9000](http://localhost:9000)
- **Backend (API)**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **База данных (PostgreSQL)**: `localhost:5432`

Скрипт `start.bat` автоматически откроет веб-интерфейс в браузере после запуска.

## 🎯 Первое использование

1.  Откройте **веб-интерфейс** по адресу [http://localhost:9000](http://localhost:9000).
2.  Перейдите на страницу **"Синхронизация"**.
3.  Настройте подключение к OData 1С и выполните синхронизацию номенклатуры, единиц измерения и спецификаций.
4.  Перейдите на страницу **"План"** для просмотра и редактирования планов производства.
5.  Для анализа состава изделия используйте страницу **"Спецификация"**.

## Пересборка проекта

Если вы внесли изменения в код `backend` или `frontend`, необходимо пересобрать Docker-образы. Для этого используйте скрипт:

```cmd
rebuild.bat
```
Этот скрипт остановит контейнеры, пересоздаст образы без использования кэша и снова запустит их.
