# Рекомендации по настройке буфера и планирования

## Проблема

Система планирования может создавать избыточные заказы на производство деталей, даже когда они уже есть в наличии. Это связано с тем, как учитывается буфер при расчете потребностей.

## Текущее поведение

1. **Буфер добавляется к планируемому количеству** независимо от наличия деталей на складе
2. **Среднесуточный спрос умножается на дни буфера** и добавляется как минимальное количество к заказу
3. **Текущие запасы не компенсируют буфер**, что может привести к избытку

## Рекомендации по настройке

### Вариант 1: Временное отключение буфера

Если вы используете сдвиг начала производства на диапазон буфера, возможно, буфер в расчете количества не нужен:

```json
{
  "production_resources": {
    "buffer_days": 0
  }
}
```

### Вариант 2: Уменьшение значений буфера

Установите меньшие значения буфера, особенно если сдвиг производства уже учитывает необходимость наличия запасов:

```json
{
  "production_resources": {
    "buffer_days": 1  // вместо большего значения
  }
}
```

### Вариант 3: Использование оптимального размера партии

Если важнее экономия на размере партии, чем буфер, установите оптимальный размер партии в карточке номенклатуры:

```json
{
  "items": {
    "optimal_batch": 50  // оптимальный размер партии
  }
}
```

## Рекомендации по использованию

1. **При сдвиге производства** на диапазон буфера, рассмотрите возможность отключения буфера в расчете количества
2. **При отсутствии сдвига производства**, используйте буфер с осмотрительностью, учитывая текущие запасы
3. **Проводите регулярный аудит** создаваемых заказов, чтобы выявлять избыточное планирование
4. **Тестируйте на исторических данных** перед внесением изменений

## Проверка эффективности

- Сравнивайте количество создаваемых заказов до и после изменений
- Мониторьте уровень запасов после внедрения изменений
- Оценивайте выполнение сроков поставки

## Технические детали

Буфер учитывается в:
- `OrderQuantityCalculator._calculate_buffer_qty()` - расчет количества буфера
- `resolve_buffer_days()` в `planning_service.py` - определение дней буфера для изделия
- Поля в базе данных: `production_resources.buffer_days`, `items.optimal_batch`
