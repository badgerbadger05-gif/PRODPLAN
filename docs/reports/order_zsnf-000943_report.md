## 📝 Расчёт remaining_qty

Для каждой позиции продукции:

```
remaining_qty = ordered_qty - produced_qty
```

Где:
- `ordered_qty` — сумма `Количество` из `Document_ЗаказНаПроизводство_Продукция` по `(order_ref1c, line_number)`
- `produced_qty` — сумма `Количество` из `Document_СборкаЗапасов_Продукция` по связанному заказу

**Пример для строки 1:**
- ordered_qty = 3 (из заказа)
- produced_qty = 3 (из сборки)
- remaining_qty = 0
